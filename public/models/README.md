# Computer assets

## Classic Laptop

- Creator: Arrangemonk / Poly Haven
- Source: https://polyhaven.com/a/classic_laptop
- License: CC0, https://polyhaven.com/license
- Downloaded: 2026-09-18
- Files: `classic-laptop/classic_laptop.gltf`, `classic_laptop.bin`, and three 2K JPEG textures.

The original mesh and textures are served locally. The application clones the
model, tints its casing, replaces the display material and screen UVs, and animates
the separate lid. A material UV correction replaces the manufacturer's bezel and
outer-lid badges with adjacent unmarked casing from the same texture. Geometry
and image textures are shared between computers.

Hookdeck's server console is original procedural geometry in
`src/ComputerHardware.tsx`. No Sketchfab model files are included.
